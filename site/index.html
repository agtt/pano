The server panel that keeps your server patched while you sleep.

runs Node, Bun, Python and PHP apps and their databases on your own Linux server. It deploys from git, gets HTTPS on its own, and every night it checks for vulnerabilities, applies security updates and backs everything up. Free and open source.

curl -fsSL https://raw.githubusercontent.com/agtt/pano/main/install.sh | sh

Run as root on AlmaLinux or Rocky 9, Debian 12–13, or Ubuntu 22.04 or 24.04. Releases are signed and the installer checks the signature first.

Small enough to forget it's there.

One 87 MB binary. No Docker, no licence server. PHP, Python, databases and the malware scanner are only installed when something needs them.

Built so a hacked web page can't become a hacked server.

The part that faces your browser has no power of its own. Everything that matters goes through a small root agent that checks each request and asks you for a fresh 2FA code before anything risky.

  1. YouOver an SSH tunnel or the built-in VPN. Password plus a 2FA code.
  2. Web UIRuns as an unprivileged user in a sandbox. It can ask, it can't act.
  3. Root agentA fixed list of typed operations. Validates every argument and checks the 2FA code itself.
Nightly vulnerability scan
OS advisories, app and site lockfiles, Node.js, PHP and WordPress core. Serious findings reach you on Telegram.
Patches without you
OS security updates, PHP patch releases and the web server update themselves and roll back if a site stops answering. App dependencies are reported, never changed.
Safe kernel reboots
New kernels are booted in a quiet window, every app is checked afterwards, and the old kernel stays ready.
2FA on risky actions
Reading a secret, changing what an app runs, adding a domain, granting database access, restoring data. Not only at login.
Nothing public but your sites
The panel and SSH sit behind built-in WireGuard. Databases stay local unless you open one, and then only over TLS.
Every app in its own box
Its own Linux user, a read-only system, a syscall filter and a memory cap. Sites are served without following symlinks, so one hacked site can't publish another's files.
Backups an attacker can't erase
Encrypted with AES-256 before upload. Mark a store as protected and the server can no longer delete from it.
Audited
The whole codebase was reviewed by Claude Mythos 5.2 before release, and every finding was fixed. Found something? Report it privately.

What it does all day.

Deploy from git
Push to GitHub, GitLab, Gitea or Forgejo. The new release builds in a sandbox, starts next to the old one and only gets traffic once it's healthy. Rollback takes seconds. Every branch can get its own preview link.
Node, Bun, Python and PHP
Next.js and monorepos, Django, FastAPI and Flask, PHP 7.4 to 8.5 and WordPress. Each app or site runs as its own user with its own runtime version.
HTTPS on its own
Caddy at the edge: Let's Encrypt certificates, HTTP/3 and security headers. The config is checked before every reload.
Databases in one click
MariaDB, PostgreSQL and Valkey on demand. The app gets its DATABASE_URL directly, so the password never reaches your browser.
Cron jobs and queues
Every job of every app on one page, with last and next run, logs and alerts when one fails.
Recover a whole server
Keep the one-line recovery kit in your password manager. On a new server, install and recover bring back admins, databases, sites and app data, then redeploy every app.
Move in from cPanel or CyberPanel
Import cPanel backups, or move sites from a live CyberPanel server one at a time while the old panel keeps serving.
Updates itself
update starts the new release first and rolls back on its own if it doesn't come up within a minute.
